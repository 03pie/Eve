# 使用 Eve 扩展

按 **Ctrl+Shift+X** 打开扩展中心。默认安装的「Ela 桌面」在「内置」筛选中可见。首页继续显示当前工作区的业务实例卡片。

## 从文件安装

1. 在扩展中心选择「从安装包安装…」，打开一个 `.evepkg` 文件。
2. 核对名称、发布者、版本、扩展类型和 SHA-256。包内包含会在工作台进程运行的原生 DLL，使用你信任的来源。
3. 选择「确认安装」。首次安装业务扩展会在当前工作区创建并启用一个实例。已有该扩展的工作区会沿用保存的实例和配置，包括手动停用的实例。

安装记录属于当前 Windows 用户。打开另一个工作区后，可在扩展中心选择已安装的业务扩展并点击「启用」。需要多个实例时，使用「添加实例」指定实例名和配置。「查看日志」打开输出面板中的对应来源。日志随工作区归档。[运行日志](runtime-logging.md)

旧工作区只记有开发清单别名时，扩展中心会显示缺失的插件标识。选择声明同一插件标识的业务包即可恢复，也可以继续使用启动参数 `--module <module.json>` 装配开发版本。

## 更新、停用和卸载

| 操作 | 生效范围 |
| --- | --- |
| 停用 | 停止当前工作区中该扩展的实例。首页卡片可单独开关某个实例。 |
| 从文件更新或重装 | 选择同一模块的包。已加载的 DLL 继续用于本进程，扩展中心会标出需要重启的更新。 |
| 卸载 | 从当前用户的扩展目录移除，当前工作区停止相应实例。其他工作区在下次启动时看到缺失引用。 |
| 恢复缺失扩展 | 在扩展详情选择安装同一模块的包，沿用原实例名称、配置和启用状态。 |

## 切换桌面

安装桌面类型的包后，在「设置 → 桌面」选择桌面，或在扩展中心筛选「桌面外壳」。选择「设为下次启动的桌面」，再选择「重启工作台」。工作台先保存当前工作区并完成清理。卸载当前使用的第三方桌面前，先切换到 Ela 并重启。

如果所选桌面无法加载或显示，工作台会尝试恢复 Ela。也可从程序目录运行以下命令，单次使用内置桌面，进入扩展中心修复或更改选择。

```powershell
.\eve_plugin_workbench.exe --safe-desktop
```

开发者可用 SDK 中的 CMake 模板生成业务或桌面安装包。当前包格式面向 Windows x64、匹配工具链的驻留 Qt 模块，分发方式为本地文件。[外部扩展开发](sdk-consumer.md)
