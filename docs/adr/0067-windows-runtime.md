# ADR-0067 Windows 工作台运行时的安装边界

工作台和日志查询工具在同一目录装载共享 Core、Qt、UI 和 Ela 库。桌面构建目录还含有测试程序和模块夹具。SDK 安装规则则提供插件开发所需的头文件与导入库。这三种目录各有用途。

发行构建显式启用 `CORDIS_INSTALL_RUNTIME`，安装器调用 CMake 安装组件 `CordisRuntime`，将结果写入新的暂存目录。组件以 Release x64 目标为输入，部署动态 Qt、Windows 平台与样式、图片解码器以及配套的 MSVC 可重分发运行库。Qt 插件目录由随包的 `qt.conf` 指定。安装器负责桌面集成和卸载，工作区和日志仍由平台按用户选择的位置管理。

外部插件继续使用独立 SDK。验证时应在移除开发工具路径的环境中启动安装后的工作台，验证 Windows 桌面、图片解码、日志查询和退出。发行目录中的许可材料与所选 Qt 版本、WebP 插件和 Ela 内嵌资源对应。
