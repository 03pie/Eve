# ADR-0019：内置配置子树的真实协调

日期：2026-10-25。范围：Q4c2c2，基于 [Core 跨代上下文桥](0018-activation-context-bridge.md) 扩展 [配置驱动](0016-kernel-configuration-driver.md)。

## 配置路径与所有权

KernelReconcileDriver 支持任意已校验深度的 builtin children。顶层由 Kernel.mount 创建，子项只通过直接父实例当前有效的 Context.inject 创建；不是把扁平化子路径偷偷挂成独立根实例。配置路径映射与插件自己动态创建的子实例分开，Core 仍统一拥有父代的全部子资源，不识别 YAML 或 Loader 类型。

子项继承父项的 realm 别名视图，局部声明覆盖同名服务。驱动在运行输入副本上物化继承视图，不修改候选原文或结构；类型化 effectiveInject 按该视图解析精确服务键。挂载时再次使用实际父 Context 派生视图，预检和真实执行一致。已禁用子项仍检查插件、类型目录和域别名，effectiveDisabled 保留父禁用级联。

父代退役由 Core 先停止全部子树，等待子、消费者及租约静止后才清理父资源。子项自身更新不扩大父重启范围。父重启或替换后，子实例身份随新父代重新建立，不能从旧 Context 创建资源。

## 规划与恢复

原有精确类型/版本/能力的依赖排序增加父到子的所有权边。启动父先于子、提供者先于消费者；删除反向执行。父依赖自身后代的输出在接受前被联合图拒绝，跨根消费另一根的配置子项输出可以正常排序及恢复。输出键跨仍启用路径转移仍受显式移除阶段限制。

没有活动父代时，只记录已经执行到的子项意图，返回 Pending，不调用 activate，也不创建实例标识。RunningEntry.waitingForParent 明确区分这种状态；已挂载子实例的 parentEpoch 表示实际父代，failure 表示真实激活或后台挂载错误。未执行的新路径不因目标已接受而出现在运行表中。

驱动在 apply 开始后接纳该动作的完整目标作为当前运行意图；preflight/plan 不修改目标或挂载资源。父实例成功激活后用一次性的 whenActiveAfter 观察后续代次，再通过独立 FIFO 工作项恢复已登记的子路径。恢复按当前运行意图重新检查禁用、存在性、继承域及类型化契约，仅补齐缺失或已经 Disposed 的子实例，不擅自创建计划尚未执行的新子项。旧实例标识的迟到通知不能控制替代实例。

恢复与单个配置动作串行，活动动作结束后再检查；虚拟宿主调用期间拒绝嵌套 apply，close 仍可重入。父恢复可能在后续子动作执行前已完成同一目标的子项重建；子动作核对实际输入，不重复替换已经满足目标的子实例。尚无实例的等待记录允许直接更改插件、域和契约，不要求先停止不存在的实例。

A 在途时接受 B、再由 C 替代 B，保留真实已发生部分，并在安全检查点对 C 再规划；没有执行的 B 新子路径不后台抢先创建。历史 PlanReport 的 Pending/Failed 不因后来自动恢复而改写，实际状态通过快照读取。

## 失败与退出

初次父激活失败使当前计划失败，未执行的子项保持未创建；显式接受目标可重试父/子失败实例。后台恢复只补齐子身份，不反复重试同一个失败激活。清理仍有残留时，不能继续接受不安全动作；后台重建的非静止失败也会冻结驱动业务入口，快照保留实际错误，原历史 Pending 报告保持。

关闭先关门、广播全部真实实例 stop，等待在途动作和所有清理回执。只有等待记录时没有虚构的 stop；关闭中从同步重入挂载返回的真实实例也加入关闭屏障，不能漏出资源。成功时清空运行记录，失败保守保留；不关闭共享 Kernel 的无关宿主实例。调度投递失败沿用跨线程门禁，不从 worker 修改运行表。

## 验证及后续

真实 Kernel 场景覆盖三级子树、独立子更新、异步子清理阻挡父重启、禁用/删除、父/子 Pending 及服务退役后的自动重建、继承/覆盖域和附加契约、联合环、最新目标替代、父/子显式重试、后台关闭与非静止失败，以及跨两棵子树的服务/清理租约。等待记录变更另有回归，避免把未挂载意图当作真实实例。

cordis_reconcile_demo 使用两份 YAML 父子目标：提供者拥有消费者子项，父配置更新后验证新子身份和最新服务值，最后确认全部资源静止。工具链、ASan 及日志见 [开发记录](../p3-development.md#q4c2c2-显式配置子树协调)。

本文保留子树阶段的边界：不覆盖原生动态模块或管理页编辑/保存。后续配置会话、可选配置页及 Store/驱动装配已按 [ADR-0020](0020-configuration-session-ui.md) 接入；统一 Home/管理路由、watcher/后台 I/O 和专用资源屏障仍待实现。不能据此宣告全部 L01–L04/S05、跨 ABI 或物理卸载验收通过。
