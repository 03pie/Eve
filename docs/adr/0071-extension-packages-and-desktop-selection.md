# ADR-0071 本地扩展库、工作区实例与可切换桌面

日期 2026-11-27。状态为已采纳。

## 背景

0.2.1 的正式工作台只装配一个开发清单，首页“添加插件实例”只从已经注册的类型创建实例。官方 Ela 随程序安装，桌面桥与产品一起构建。扩展中心需要独立于工作区内容才能在空白或引用缺失时提供修复入口。

## 决策

- 扩展包使用 ZIP 容器和 `.evepkg` 后缀，分为 Qt 业务扩展和桌面外壳。包元数据独立于现有模块清单。安装前读取清单和显示信息，用户确认本地来源后复用现有不可覆盖的哈希安装事务。版本和选择属于当前用户，实例配置和启停属于各工作区。
- 业务包安装成功后在当前工作区恢复已有实例或创建一个默认实例。重复安装幂等。已映射的 Qt 映像驻留到进程退出。更新记录下次运行的版本，卸载保留用户实例配置，缺失项可以重新安装恢复。
- 扩展中心使用 Ela 原生导航、菜单及列表详情布局。首页保持业务实例卡片。文件菜单、快捷键和命令面板连接同一动作。日志归档沿用宿主运行日志。
- 默认桌面来自只读的随包 Ela 模块。用户可以通过单独的桌面 SDK 自定义窗口布局并复用平台能力，选择已安装桌面后经保存和正常重启生效。启动回执确认前的候选失败应恢复 Ela。`--safe-desktop` 提供独立于第三方窗口的恢复入口。普通业务扩展保持 0.2.0 SDK 契约。
- 通过外部 SDK 工程、两个同时安装的业务包、旧版工作区、有缺失引用的工作区、真实桌面选择和本机升级进行验收。业务插件源代码继续由各自独立项目维护。
