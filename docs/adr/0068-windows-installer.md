# ADR-0068 Windows 桌面安装器

发行物面向安装 Cordis 工作台的 Windows x64 用户。选择 Inno Setup 6.6 以上的现代向导，复用系统明暗模式、键盘导航和项目自有的 Eve 图标。使用者可以选择安装位置和桌面快捷方式。Qt 和 MSVC 运行依赖随安装包提供，安装过程支持离线执行。[Inno Setup 向导样式](https://jrsoftware.org/ishelp/topic_setup_wizardstyle.htm)

发行版本取自根 CMake 项目。CMake 的运行时安装组件负责选择程序、依赖与声明，安装器只读取本次构建新生成的暂存目录。沿用桌面开发脚本初始化 MSVC 和 Qt 环境。打包命令生成安装程序与 SHA-256 校验文件，平台 SDK 继续通过原有组件交付。

安装范围为当前 Windows 用户。稳定的应用标识用于后续版本识别，开始菜单与可选桌面快捷方式指向安装的工作台。工作区、日志及界面偏好按现有宿主路径保存，卸载仅移除安装器所拥有的文件。首次发布以实际安装、同路径覆盖安装、桌面启动、归档读取和卸载验证这一边界。对外发布由维护者单独执行。
