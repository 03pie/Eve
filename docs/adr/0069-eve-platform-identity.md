# ADR-0069 Eve 平台与开发接口命名

Eve 沿用本仓库既有的 Cordis C++ 插件内核和生命周期模型。0.2.0 统一桌面产品、源码、SDK 和发行工具的名字。此前发布的架构决定和 Git 历史保留当时的项目名，现行文档使用 Eve。第三方版权声明、插件作者分配的标识和已有工作区内容各自保留原义。

Core 继续负责实例、服务依赖和资源清理。Loader、Module、Replacement、Qt 与工作台的依赖方向维持现有设计。开发者从 `eve/` 与 `eve_abi/` 引入头文件，使用 `eve::` 命名空间、`Eve::` CMake 目标与 `find_package(Eve)`。Native 导出入口、Qt 工厂 IID、SDK 元数据和共享库配套换名。已有插件需使用匹配的 Eve SDK 重新构建。对加载旧二进制的拒绝在装载阶段验证。

Windows 发行沿用产品安装标识以识别旧版，首次安装使用 Eve 的产品名和路径。升级应保留用户的工作区、偏好和日志，并能读取旧版归档。旧存储名只在兼容读取或定位已有数据时使用。新安装包、日志工具和开发脚本均使用 Eve 名称。

验证分三层进行。使用 Core 预设检查命名空间、头路径和平台目标；使用桌面预设和安装树 SDK 验证 Native 与 Qt 模块契约；从 Cordis 0.1.5 安装升级到 Eve，核对启动入口、旧数据访问、快捷方式和卸载行为。
