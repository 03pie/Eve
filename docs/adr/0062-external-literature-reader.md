# ADR-0062 文献阅读插件与仓库外 SDK

2026-11-24。P7 的使用者是需要在本地阅读、整理和继续批注文献的读者。P6 的技术预览基线为 `2733827`。

## 交付与依赖

读者将一篇 PDF 导入个人文献库，在工作台内阅读原文、翻页、缩放、记笔记，正常关闭后继续阅读。新版增加书签操作。源 PDF、笔记、阅读位置与插件版本分别拥有独立生命周期。机器上的 Windows PDF 服务负责解释 PDF，插件在工作线程逐页渲染。可观察的成功条件包括真实页面图像、重开时同一篇文献及页码、已保存的笔记和升级后可继续写入的数据。

P6 示例业务入口显式固定 Counter、Reporter、Notebook 的工厂、名单、升级操作和界面。P7 增加轻量的 Qt UI 插件工作台入口，接受用户选择的受信任模块清单。相同的 ModuleManager、Qt 预检及运行工厂负责模块与 Core 身份，Kernel 和 ConfigurationSession 负责实例、依赖和配置。ElaShell 继续拥有窗口和贡献退出顺序。宿主提供页面、命令、输出及下述调度器服务。默认运行包把阅读插件装在约定的模块目录。阅读器的解析、数据格式、笔记以及界面都在 DLL 内。

开发者使用已安装的 Cordis CMake 配置和匹配的共享 Core、Qt、Ui 库，从独立源码目录构建插件。相同编译器、Qt 版本和动态 CRT 是该 C++ SDK 的消费契约。SDK、插件源码和面向读者的运行包分别交付。安装接口与最小模板见 [SDK 开发记录](../p7-sdk-development.md)。

现有 QtValueWorker 要求使用创建 Kernel 的同一 QtScheduler。工作台通过类型化服务 `qt.scheduler/v1` 将这个实例交给受信任插件，用于托管工作与主线程结果投递。调度器与队列的关闭仍归宿主。

## 状态与恢复

配置会话保存实例路径、插件标识和业务数据根。用户可为多个实例选择不同文献库。插件管理导入内容和单独的业务索引，显式保存笔记，界面标示尚未保存的编辑。并发写入必须比较原基线，错误或冲突保留可恢复数据。阅读器关闭时停止后台作业，在页面消亡后丢弃迟到的显示结果。进程自然退出后，从相同数据根运行新版本。Qt 模块沿用进程驻留策略。

## 验收

在仓库外构建并实际加载 SDK 模板和阅读器。检查多实例隔离、依赖未就绪及恢复、工具链不匹配和损坏包的诊断。用连续阅读会话验明 PDF 页面、保存、重开、真实两版升级及故障后的重试；核对安装前缀搬迁、运行包依赖和准确产物。依据实际运行范围记录限制。工作区和 P6 的既有运行包分别保留。
