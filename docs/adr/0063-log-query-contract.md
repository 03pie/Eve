# ADR-0063 日志来源查询的完整性

## 背景

日志解码器在读到截断或损坏的分段时，同时返回可读记录和诊断。分页和导出可以取得诊断，独立查询工具列举来源时曾丢弃诊断，使自动化调用把部分列表当作完整结果。

## 决策

宿主私有的来源查询同时返回来源目录与读取警告。当前运行使用内存目录，历史运行复用同一解码器。只有完整扫描的历史目录可以进入缓存。命令行 `--sources` 保留已读来源的输出格式，在标准错误报告读取警告，并以非零状态结束。正常归档及有效的空归档返回成功。

输出编辑器的文本块上限归界面维护，分页和续读的条数上限归查询层维护。两者分别约束界面文档和查询结果，继续沿用既有数值。

## 验证

`logging.l6_query` 使用真实命令行程序读取完整、空和截断的工作区归档，对照标准输出、标准错误及退出码。现有分页、续读及归档导出测试继续验证读取顺序和事件范围。
