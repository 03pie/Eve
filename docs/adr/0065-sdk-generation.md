# ADR-0065 外部 Qt 插件的生成与安装契约

SDK 的 CMake 助手从消费者读取模块 ID、插件 ID 和模块版本，在配置时生成 Qt metadata，链接后由清单写入器记录实际产物摘要。宿主在装载时独立验证这些字段。先前两端的标识符规则不同，模板工厂中重复填写的插件 ID 也可能与 metadata 脱节。

生成端的助手与清单写入器共用同一份字段校验，接受范围以宿主预检为准。插件目标私有的编译定义把消费者声明的 ID 传给模板工厂。安装时按生产者版本展开模板的精确版本要求。外部插件的清单格式、Qt 工厂接口和宿主校验机制继续沿用原契约。

SDK 沿用头文件的安装布局以兼容已有消费者，支持范围由导出目标和消费指南界定。安装目录提供指南及其引用的许可材料。独立消费者测试从安装前缀构建，使用自定义 ID 装载页面，并覆盖生成端的拒绝边界。
