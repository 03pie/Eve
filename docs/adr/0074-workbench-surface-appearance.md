# ADR-0074 工作台材质与主题

日期 2026-11-28。状态为已采纳。

工作台的窗口和独立工具窗负责绘制壁纸、Ela 背景和 Windows 材质。由 `WorkbenchPreferences` 应用系统透明与对比度策略。Windows 材质是否应用由各自窗口的 HWND 决定，单个工具窗应用失败时采用当前主题的实色背景。

顶层窗口的 `QPalette::Window` 留给材质层。Ela 云母使用该笔刷绘制纹理，原生材质使用透明笔刷露出 DWM 背景。标准外观和系统回退的底色由窗口按当前策略绘制。切换主题时同时刷新控件的文字、选中状态和底色。

内容区使用同一 Ela 调色板，将透明内容、控件底色和弹层分别交给各自的绘制角色。透明内容包括文档、滚动区域和编辑器底层，由对应窗口提供背景。卡片和普通操作使用 Ela 的半透明角色，在透明材质下露出底层，主要操作保留强调色。菜单、通知和快速打开使用随主题切换的弹层底色，确保覆盖其他文字时仍清楚。品牌插图维持自身颜色。

页签和覆盖式弹层沿用 Ela 控件的小圆角。工作台的中央面板和状态栏沿用各自的绘制逻辑，面板圆弧落在控件边界内。圆角由绘制负责，现有布局、分隔线、键盘焦点和操作范围沿用原有控件管理。

工作台向 Qt 原生工具提示提供默认主题样式，提示内容更新时沿用当前来源控件的样式层级。插件可通过自己的控件样式定制工具提示。

宿主样式私有，独立业务插件通过 SDK 贡献的控件仍由作者配置。Windows 桌面亚克力和系统云母的失焦外观由系统组合器管理。
