# ADR-0072 首页插件卡片与扩展详情窗口

日期 2026-11-27。状态为已采纳。此决策更新 ADR-0071 的桌面导航与详情展示方式。

## 决策

首页承担插件浏览入口。已安装扩展、尚待恢复的引用和工作区实例共用现有 Ela 卡片。已有实例保留自己的开关与配置入口，点击卡片可查看所属扩展及当前实例。桌面扩展和没有实例的已安装扩展也能从首页找到。

详情使用工作台持有的 Ela 窗口。顶部展示图标、名称、发布者、版本和主要操作，正文展示扩展介绍、标识及当前工作区可用的管理操作。展示内容取自本地清单和真实工作区。布局参考 VS Code 扩展详情中将扩展说明与安装、管理动作放在一起的设计。[VS Code 扩展详情](https://code.visualstudio.com/docs/configure/extensions/extension-marketplace#_extension-details)

文件菜单、命令面板和首页安装入口使用同一套文件选择与预览确认流程。`Ctrl+Shift+X` 和桌面 SDK 的 Extensions 动作回到首页卡片。设置中的桌面选择复用已安装的桌面扩展以及同一详情窗口。扩展详情的打开和关闭不产生页面节点、页签或历史项。

## 所有权

宿主继续通过 `ExtensionControls` 提供目录值和变更回执，原有工作区管理服务负责实例动作。首页保存可展示的快照和稳定标识。窗口关闭、安装失败或重选卡片时，界面核对回执的目标与对象生命周期。安装状态、启用目标及真实运行状态沿用各自的数据来源。

## 发布验证

从 0.3.0 增量打包时发现，Qt 元对象编译器可能沿用上一版的桌面元数据，而新安装清单已经写入 0.3.1。官方桌面工厂应与独立插件一样，将生成的元数据 JSON 声明为元对象编译步骤的文件依赖。宿主继续核验实际 DLL 和清单的一致性。
