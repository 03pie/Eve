# ADR-0073 工作台顶栏与快速打开

日期 2026-11-28。状态为已采纳。

顶栏采用左侧应用菜单、中间导航历史与快速打开、右侧布局控制及窗口按钮的布局。延续 Eve 品牌、Ela 调色板和原生窗口拖动、缩放行为。根据控件实际所需宽度折叠菜单和辅助入口，系统窗口按钮独立留位。置顶和主题切换通过视图菜单提供。[VS Code 标题栏](https://github.com/microsoft/vscode/blob/fe444ae00bd0ab083135f2e5f2340adf1314b69d/src/vs/workbench/browser/parts/titlebar/titlebarPart.ts#L515-L591)

点击顶栏按钮或按 `Ctrl+P` 打开页面模式，`Ctrl+Shift+P` 或输入 `>` 进入命令模式。快速打开使用一个由根窗口拥有的浮层和搜索框。页面结果来自工作台的已发布页面和现有导航历史，通过稳定页面键回到原导航门禁。命令结果沿用现有服务模型、发布门禁和执行回执。选择时重新校验目标，关闭或取消时处理键盘焦点。撤页和工作台关闭同步更新快速打开入口。[VS Code 命令中心](https://github.com/microsoft/vscode/blob/fe444ae00bd0ab083135f2e5f2340adf1314b69d/src/vs/workbench/browser/parts/titlebar/commandCenterControl.ts#L45-L124)

顶栏控件、菜单、快捷键和布局操作复用同一动作。导航按钮对应 Ela 展开与紧凑状态，面板按钮对应实际的输出与问题可见状态。外部桌面仍通过现有 LayoutServiceV1 装配工作区和调用平台动作。职责边界沿用桌面模块、UI 服务及工作台控制块。

外部桌面接管窗口布局时，原生顶栏退出键盘导航。通过平台动作打开的浮层从工作区顶部展开，外部桌面卸载后恢复顶栏。

默认 Ela 顶栏在原有高度内为内置图标、窗控和工作台按钮提供同一条 30 像素内容行。最大化按钮的命中边界从顶栏上沿计算，留出窗口缩放边缘。工具按钮统一使用 Ela 图标，键盘焦点由 Ela 样式交给 Qt 绘制。
