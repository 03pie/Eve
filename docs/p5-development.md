## 必须保持的边界

- 模块目录只管理产物、代次、后端与引用；替换协调器管理运行闭包和事务。Core 不反向依赖 Module/Loader/UI。
- 候选验证不改变当前运行、期望目标或已保存配置。一个模块最多一个替换操作，配置仍可编辑，但冲突目标与管理动作不能越过锁。
- 先验证新代 PluginId、接口 major 与 schema；关闭旧消费者/提供者并确认完整清理后才启用新代。旧代未静止时不得接管同一服务键。
- 新代 staging 输出不对闭包外消费者开放；只有提供者与全部消费者实际恢复才提交成功。消费者恢复失败必须使 ReplacementReport 非成功（S09）。
- 迁移只传版本化、独立拥有的值数据，先校验后提交；不迁移 Context、QObject、裸指针、STL 对象或服务句柄。恢复使用保留的旧配置与旧工厂。
- 当前 P4 的 Windows PIN 不可撤销。可卸载代次必须在初次装载时按白名单选择独立策略，不能把历史驻留代强行 FreeLibrary。所有任务、捕获、deleter 和对象先完整释放；卸载失败仍保留诊断与所有权。
- Qt UI 当前适配器固定 resident。白名单仅向具备明确卸载契约及实测证明的后端/插件开放，不把页面关闭当作 Qt 模块可卸载证明。
- H02 必须真实完成 Windows 连续 100 次替换并核对引用、句柄/对象基线及驻留解释，不能用目录预算测试或重复预检替代。

## 本阶段记录

M1 的结构、公开入口、真实 DLL 场景及审查证据见 [M1 记录](p5-m1-development.md)及 [ADR-0041](adr/0041-module-candidate-generations.md)。后续阶段仅在 M1 审查、验证、提交和远端同步完成后开始。

M2 分段实施：M2a 独立 hash 目录安装事务先保护磁盘产物，见 [记录](p5-m2a-development.md)和 [ADR-0042](adr/0042-module-artifact-installation.md)；审计、提交并同步后，继续 Core 的候选输出发布边界及上层运行替换协调。完整 M2 仍须满足表中的操作所有权、闭包锁、停止/创建顺序和原子切换，不以 M2a 替代。

M2b 在同一服务索引中提供 Held/发布组、成员就绪提交和放弃清理，见 [记录](p5-m2b-development.md)与 [ADR-0043](adr/0043-controlled-service-publication.md)。M2c 再接模块与运行闭包操作所有权、锁、版本核对、停止/创建顺序和目录切换；UI 贡献的可见性由后续 UI 适配层接入，不能把 Core 服务隔离当作全部业务副作用可回滚。

M2c1 先补齐实际服务/等待声明图与 Kernel 所有权上的只读闭包，见 [记录](p5-m2c1-development.md)及 [ADR-0044](adr/0044-replacement-dependency-closure.md)。常规快照保持原布局与开销，查询返回值不授予替换权。按要求审计、提交同步后，下一段实施模块/闭包排他事务；仍须完成定义与冻结目录协同、目标版本检查、真实停止/创建和整体切换，不能把计算出的 stopOrder/startOrder 当作执行或成功证明。

M2c2 在唯一 Core 账目上实现不可复制的排他作用域、冲突管理/服务入口门禁、旧业务冻结、有序停止与失败保留，配置冲突在目标 CAS 前拒绝，未变更条目通过解除通知恢复；见 [记录](p5-m2c2-development.md)和 [ADR-0045](adr/0045-replacement-scope-ownership.md)。SDK 更新 0.1.1，宿主及 C++ 插件一起重建；C ABI 不变。本段审计提交同步后，后续 M2c 仍须接模块逻辑锁、ReplacementOperation、冻结定义/schema/目标版本与实际工厂重建，最后整体提交服务和目录角色；现有 Core 作用域不授予候选代成功或卸载能力。

M2c3 在同一进程目录实现当前/候选代的唯一模块预约，原生/Qt 实际工厂和已创建定义共用准入；同模块所有代次的装载/入场参与排他，暂存与 drain 使用同一同步边界，见 [记录](p5-m2c3-development.md)及 [ADR-0046](adr/0046-module-replacement-reservation.md)。本段预约没有破坏性动作，必须由后续 ReplacementOperation 持有到运行提交或恢复结束；冻结定义/schema/目标核对、授权候选创建和服务/目录整体切换仍待后续 M2c，不以预约成功代替业务验证或整体升级成功。
