# 工作台 UI 优化

日期：2026-10-27。基于当前 Release 原生窗口和第一方 UI 实现检查；本轮是 P3 完成后的界面改进，P4 仍未开始。参考 [VS Code 界面分区](https://code.visualstudio.com/docs/editing/getting-started/userinterface)，复用项目内的 Ela 控件与明暗主题。

本审查已纳入 [UI 设计与优化专项](ui-optimization-plan.md)，作为第一轮问题与实现证据；后续工作包和优先级以专项计划为准，实时状态见 [开发进度](progress.md#ui-设计与优化专项)，验收使用 [专项验收单](../tests/acceptance/ui-optimization.md)。

本页保留首轮审查的历史观察。后续 Ela 组件/字体统一、状态/偏好/键盘实现及 444/444 双配置、ASan 104/104 和新版用户确认见 [UI-S0 验证](ui-optimization-verification.md)；当前推进顺序已改为 [五个专项阶段](ui-special-stages.md)。

## 设计方向

左侧活动栏用于插件入口，中央页签用于已打开的页面，插件自己的资源树放在插件页内部。底部命令/输出按需展开，状态栏保持轻量。前进后退、页面搜索、全部页签可关闭、零页签空白等已确认交互继续保留。

视觉上采用紧凑的工作台框架、有层次的内容区、克制的主要操作色。Home 保留 Ela Example 风格的品牌横幅；配置、管理等工作页面优先提供信息密度与明确反馈。

## 观察与本轮修改

| 当前观察 | 修改 | 目的 |
|---|---|---|
| 菜单栏固定 250px，原生窗口中帮助项进入溢出菜单；搜索固定 300px | 菜单采用自身尺寸建议；搜索按窗口宽度在 160–360px 调整 | 减少不必要的菜单折叠，给窄窗口的导航和系统按钮保留空间 |
| 配置页的标题、说明、完整路径和操作挤在上部，文字权重接近 | 统一边距、标题加粗、次级说明使用 Ela 次级文本色；路径移到编辑区标题下，过长时中间省略并提供完整提示 | 明确标题、流程、状态、工作内容的层级 |
| 五个按钮视觉权重相同，首次打开出现一排不可用操作 | 保持“检查差异 → 应用 → 保存”顺序；仅应用使用主题强调色；还原/冲突基线移到右侧，文案缩短并补充语义提示 | 区分主要流程与恢复操作，不混淆应用和保存 |
| 左侧编辑器和右侧表格没有区域标题，底部详情为空白框 | 增加“配置源文件”“期望与运行状态”“差异与执行结果”；加入运行区说明和结果占位提示 | 首次使用时能理解每个区域和空白原因 |
| 配置文本使用普通界面字体，长行自动折行；分隔条较难命中 | 编辑器使用系统等宽字体、四空格制表宽度和水平滚动；分隔条加宽，禁止折叠工作区 | 改善 YAML/JSON 编辑、列对齐和拖动体验 |
| 表格网格与大面积底色增强了表单感 | 移除表格网格、统一行高，保留 Ela 表头与行选择 | 把视觉重心放在条目、期望和真实运行状态 |
| Home 固定横幅高度，对不同文字/缩放不够灵活 | 横幅改为最小高度并按内容增长，保留品牌图案；仅管理插件入口强调，计数/说明/身份用次级文本色 | 保留展示性，同时减少主次竞争和固定高度裁切风险 |
| 页签右侧“面板”文字按钮较突兀，状态栏字号接近正文 | 使用 Ela 终端图标和可访问名称/快捷键提示；状态栏文字缩小 | 让工作台框架保持安静、内容区成为焦点 |
| 设置页下拉框占满整张卡片 | 限制主题选择器宽度，统一设置/关于页标题与边距 | 让控件尺寸匹配实际内容 |

本轮仅调整 UI 呈现，不改变配置接受、CAS、冲突基线、保存队列、插件生命周期及退出屏障。卡片仍不承担页面跳转，左右开关继续表示真实启用状态和权限。

## 后续可继续优化

- 插件管理：把运行、等待依赖、失败与停止呈现为图标和文字结合的状态，保留完整原因；需要直接使用类型化状态，避免根据中文文案猜测状态。
- 配置反馈：将运行目标、磁盘保存和外部冲突做成三个独立状态区，逐项验证同步、失败及关闭恢复，不把“已应用”显示成“已保存”。
- 工作台偏好：记住面板尺寸、导航宽度和用户主题；作为独立功能处理启动恢复、无效设置和文件读写失败。
- 细节可用性：统一焦点指示、禁用原因和空状态；继续检查中文长名称、长路径和 150% 缩放。

上述方向随后已在 UI-S0 实现并重新验证，见基线记录；首轮列表不作为当前未实现清单。当前新增的 VS Code 结构增量另按 UI-S1–04 推进，不沿用原版本人工确认。

- 第一方改动范围格式、UTF-8/LF、git diff --check、只读参考及第三方边界通过。构建/检查日志为 build/ui-polish-build-final.log、build/ui-polish-tests-release.log、build/ui-polish-colors-build.log、build/ui-polish-tests-ui.log。
