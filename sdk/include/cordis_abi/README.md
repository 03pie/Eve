# C ABI SDK（Windows x64 V1 基线）

本目录包含三个独立 C11 接口，头文件在源码和安装包中的相对位置一致。

- 模块提供身份、插件清单和卸载策略，宿主只读核对。[模块发现](module_query.h)
- 宿主与模块协商业务能力、借用值、请求生命周期和函数表容量。[业务函数表](plugin.h)
- 模块可独立声明同步状态的描述、验证、捕获和恢复协议。[状态扩展](state.h)

状态扩展使用独立 cordis_query_state_v1 符号和版本，不改变已有 plugin/host V1 表。缺失符号保持旧插件无状态；存在但拒绝或返回坏表则失败。每个实际 PluginId 的 describe 可明确返回 UNSUPPORTED；其他操作的拒绝不能解释成无状态。schema 最多 128 个可见 ASCII 字节，版本非零；JSON 为独立 UTF-8 原文，最多 1 MiB。输入只借用至调用返回，输出写宿主一次提供的缓冲区，只能修改内容和 size；不能等待、泵事件、抛异常或返回 PENDING。

Native 宿主把请求、服务和 effect 接入 Kernel 的实例生命周期。替换操作在冻结后按实际成员捕获状态，验证候选后向新实例导入，并保留原始状态供恢复使用。宿主在重建和共同提交时核验实际导入。Windows x64 C ABI 与同工具链 C++ 源码 SDK 各自协商兼容性。源码仓库中的 `docs/abi-v1.md` 和 ADR-0049 记录完整的布局与替换契约。
