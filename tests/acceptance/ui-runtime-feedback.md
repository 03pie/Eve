# 输出面板、通知与工作台交互验收

本单验收平台提供的壳层、概览、管理、配置、设置、输出、问题和通知。插件可作为实例或日志来源。插件自行绘制的页面及其业务交互延期至插件专项。本机已按以下工作单验证原生实现。实测覆盖和待验条件见[本机原生验收](../../docs/ui-native-acceptance.md)。U1 至 U6、U8 至 U12 可以独立运行，U7 单独核对正式宿主界面与真实持久日志。[运行反馈方案](../../docs/ui-runtime-feedback-plan.md) · [工作台整体改版方案](../../docs/ui-workbench-redesign.md) · [交互原型](../../docs/design/workbench-ui-prototype.html) · [日志系统工作单](../../docs/runtime-logging-plan.md) · [日志系统验收](runtime-logging.md)

## 准备

使用 Windows 原生 Qt 桌面、独立临时工作区、测试实例和可丢弃的配置文件。U1 至 U6 可向真实工作台控件连接遵守查询契约的测试数据源，预置两次运行、两个同名通道、已停止实例、过期记录和一次写盘失败。U4 经平台管理与配置界面执行真实配置操作。记录数据源类型、运行包散列、样本模块版本、Qt 平台、窗口尺寸、系统缩放和输入方式。每项登记预期值、实际现象、截图或测试记录、通过／失败及未覆盖范围。

U8 至 U12 各自初始化工作区、偏好和样本，可直接运行其中一项。验证「查看日志」入口可使用有已知来源和事件的查询测试源。U10 操作平台底部面板和宿主管理的窗口，U11 使用正式 P7 宿主和实际偏好存储。测布局时记录当前平台页面或工具窗口的实际可用宽度，单位为 Qt 逻辑像素，窗口外框和截图的物理像素另记。宽档为 ≥1080，中档为 760–1079，窄档为 <760。准备 759、760、1079、1080 四个边界点，分别记录明暗主题和 Windows 100%、150% 缩放。

## 用例

| 编号 | 操作 | 通过条件及证据 |
|---|---|---|
| U1 来源、通道与焦点 | 让 A、B 两个插件依次向同名通道写入，再为 A 增加实例并重启一代。在 A 的输出中选中文本，向 B 追加，关闭面板后继续写，再主动切换到「全部来源」。交错提交及撤销候选记录。 | 安静的插件不占来源栏。已发布的 A、B 可分别选择，实例与代次可辨，旧实例可回看，全部来源能串起同一操作。后台写入保持当前来源、选区、滚动位置和面板开闭。撤销的来源和值不进入下拉、输出或通知。记录切换前后的选中项、选区和焦点。 |
| U2 历史、筛选、定位与导出 | 选上次运行，按来源、级别和关键词组合筛选，向前翻两页并定位一个已知事件。制造空结果，恢复筛选。清空当前视图，重新查历史，再复制单条、导出筛选结果。最后查询一个已清理的事件。 | 显示正确的运行时间、版本、来源和事件；同时间事件跨页无漏行、无重复。空态可见筛选条件和恢复入口，过期事件有明确说明。清屏后历史仍可查，封闭的测试归档前后 SHA 相同。导出内容与筛选期望集合逐项相符，仅含选定范围，不含样本中用于检查泄露的配置正文和模拟凭据。 |
| U3 通知中心与免打扰 | 在平台设置搜索框编辑并选中文字时，分别触发普通成功、需要处理的警告、错误、十次相同警告，以及日志归档受阻。打开铃铛，查看对应日志，按 Esc 返回。启用免打扰后重复，重开历史。 | 普通成功在操作处反馈，需关注的事件使用所属窗口的 Ela 短提示和未读条目。重复警告聚合并显示次数，写盘受阻只出现一次持续状态。后台提示保持光标、选区和面板状态。主动定位才打开正确运行、来源和事件，返回后可继续编辑。免打扰保留历史和未读数，重开后已读状态按约定恢复，旧弹条不重播。保存短提示、历史与焦点变化记录。 |
| U4 平台操作失败与恢复 | 在「添加插件实例」中提交重复标识，修正后提交。再在工作区配置编辑器修改样本，外部写入同一文件制造修订冲突，尝试保存。先保留编辑，再明确处理冲突后保存。单独对一个已退役实例打开旧通知，检查定位及重试。 | 重复标识的原因显示在字段旁，修正后只创建一个实例。配置冲突持续显示原因、当前修订和恢复选项；单次失败至多产生一个需要处理的提醒。确认前草稿及外部文件保留，显式保存后可核对目标修订和实际文件。旧事件可按标识定位，失效动作有原因且不会操作新实例。保留错误、修复及焦点返回记录。 |
| U5 大量输出与键盘 | 提供 10 万条合成记录，模拟实时供应增量。期间持续输入、切源、暂停跟随、选择多行，全程用键盘打开输出、筛选、复制并返回原编辑位置。 | 面板按有界页消费查询结果，批量呈现新增记录，暂停时提示有新记录。核对所选范围与界面结果，记录峰值内存、UI 更新次数、请求页大小、供给速率、硬件、样本量和输入至下一次绘制延迟。建议以本机 p95 ≤ 100 ms 作为待实测确认的目标。归档与已接纳／丢弃数的 10 万条对账由 L3 执行。 |
| U6 平台导航、开关与可用性 | 明暗主题、100% 与 150% 缩放，在常用和窄窗口分别走查首页、设置、输出、问题和通知。使用零实例、多个长中文实例名和长通道名。用键盘启停所选实例、切换设置开关、从问题定位实例并返回。 | 零实例时「添加插件实例」可达；首页和文件菜单用词一致。已有多实例时能辨别目标、期望启停和实际状态，操作只影响所选实例。收起的操作从「更多」可达，可查完整来源。图标、开关和级别有名称、可读状态或文字；保存截图、实测尺寸与按键记录。 |
| U7 宿主与已发布插件输出的真实日志联调 | 用正式宿主启动进程 A，在平台配置窗口操作专用工作区，触发一次保存冲突并显式恢复。从平台反馈定位该事件。同时让实际加载的模块经正式输出服务发布带已知标记的记录，可使用无页面的日志夹具。在平台「输出」中选择该来源。正常退出 A，以同一工作区启动 B，从平台历史查回 A 的平台失败、恢复和插件记录。另用多插件宿主交错发布两个同名通道。 | 记录两个真实 PID、独立运行 ID、模块与实例身份、事件 ID 和归档原件。逐条比对 A 窗口、B 的历史查询与磁盘记录中的相同事件；平台故障恢复后当前问题状态更新，历史保留原因及结果。重开无旧弹条。多插件窗口能分别选定两个真实来源，P7 单模块入口用平台来源及同模块多实例复核。此项通过依据为真实宿主操作、实际发布记录和持久日志。 |

### U8 壳层、首页和添加插件实例

依次用鼠标展开「文件」「视图」「转到」「帮助」，查看每个下拉是否紧贴所选标题，能否移到相邻菜单。再用菜单助记键、方向键、Enter 操作一次，用 Esc 和点击菜单外部分别取消一次。展开和取消期间核对活动页、面板和业务窗口数保持原值；原生 ElaMenu 的临时菜单层单独登记。选择「帮助 → 关于」应进入原有关于页，选择「文件 → 工作区配置」才进入相应托管配置窗口。分别在已绑定和未绑定配置会话的宿主中检查「添加插件实例」的可用性和执行结果，保留截图、触发方式和焦点路径。

从零实例首页开始，用键盘经活动栏、中央页签、页面搜索、命令面板、底部面板和状态栏完成一次导航并返回。分别从首页和文件菜单打开「添加插件实例」，选择已注册模块。依次覆盖取消、缺失或重复标识、有效新建，以及同模块两个长中文实例名称。切换一个实例的启停，再从其卡片打开管理和配置。

核对首屏的实例总数和运行数，卡片的插件名、实例名、状态及可用动作应能区分同模块实例。多张卡片在宽窗横向并排，缩窄时自然换行。每张卡片独立含图标、名称、实际状态、身份路径、单开关和管理／配置操作。换行前后按同一标识操作，核对目标与键盘顺序。两个添加入口指向同一流程，写明添加到运行目标和保存到磁盘的时机。取消和校验失败保留原实例集合，有效提交只新增一个实例。切换和详情只作用于目标实例。关闭全部页签后可从活动栏或 Ctrl+P 返回，Ctrl+Shift+P 可找到相应动作。保留零实例、两实例首页、校验错误及成功结果，附焦点返回的按键记录。

在添加实例和命令搜索中分别打开 Windows 中文输入法，按 Enter 确认候选词，核对实例数及命令执行数，随后明确提交一次且只生效一次。在添加表单保留一段已填配置，先输一个重复标识，再换为另一个重复标识，错误仍关联标识框；改为可用标识后错误消退。另用两段连续无效 JSON 验证错误持续，修正后读回原输入并提交。

### U9 管理、实例配置和工作区配置

准备同一插件的 A、B 两个可区分实例。管理页选中 A 时更新 B 的运行状态，随后以键盘查看两者详情和日志定位。分别在 A、B 的实例配置中输入不同草稿，在对象间切换并返回。若界面要求先处理草稿，走一遍「继续编辑／取消切换」，再显式处理 A 后进入 B。制造修订冲突，在确认放弃或重载前核对原编辑内容及关联对象。

另从工作区配置打开独立 YAML，逐步编辑、检查差异、应用到工作台、保存到磁盘。外部修改同一文件，分别用独立副本验证载入磁盘版本只更新编辑文本、采用冲突基线保留当前目标。核对列表刷新前后选中行、焦点、滚动位置和目标身份。详情入口须定位所选实例；该实例退役后，旧操作失效且不会转向另一实例。两份实例草稿不能串写或静默丢弃。工作区配置应分别显示编辑、实际运行及磁盘修订；应用后到显式保存前核对文件内容，确认后再核对运行目标和文件修订。保存两类页面、冲突处理前后状态及文件对照。

### U10 工作台底部面板、托管窗口与焦点

在三档宽度和四个边界点分别打开设置，在搜索框保留文本选区。通过菜单、Ctrl+J 打开和收起底部面板。用键盘切换「输出」「问题」，逐次记录面板高度和分隔条坐标；筛选空结果、追加多条长日志、增减问题，窗口尺寸相同时各次坐标和高度应相等，超长内容可在页内滚动。再手动拖动分隔条、缩短主窗高度复验。用长名称、空结果和多行错误测试工具栏与详情。随后从概览卡片打开平台管理与实例配置窗口，从文件菜单打开工作区配置；在各自窗口中跨档缩放、操作次级动作并返回。

宽档能同时识别来源和工具，中档的次级动作在「更多」中可达，窄档仍能切源、筛选和关闭。底部恰有「输出」「问题」两页。用顶栏和 Ctrl+Shift+P 搜索同一条命令，核对执行对象及两次单独调用的次数；打开或取消检索时两页的选择和开闭状态保持。底部展开后中央页和面板都可操作。管理和配置在受限宽度下能查完整对象、看到编辑状态与错误、完成配置操作，切换区域保留所选对象和草稿。关闭最内层弹层先返回其触发控件，关闭托管窗口后回到有效的启动入口；后台刷新保持当前窗口、焦点和选区。记录各档面板开闭、分隔条位置、托管窗口客户区及按键前后的焦点。

### U11 设置、关于和 P7 跨进程偏好

在「设置 → 外观」找到窗口材质选择框旁的「选择背景图片」。准备图案明显不同的 PNG、JPEG、WebP 各一张和一份损坏图片，按以下次序复核。原型在本机浏览器按会话验收；正式宿主在本地 Windows 按实际偏好保存范围另行登记。

| 背景操作 | 预期结果与取证 |
|---|---|
| 在标准材质下用键盘激活「选择背景图片」，选择 PNG。在 Acrylic 下再选择 JPEG，在另一种材质下换成 WebP。 | 每次按键直接打开系统文件选择器。解码成功后当前窗口立即显示新图，原地查看导航、中央画布和展开的底部面板。保留同一窗口尺寸下更换前后的对照图。 |
| 取消一次选图，再选损坏文件。随后切换概览、设置、关于，切换浅深主题并轮流选择六种材质。 | 取消和解码失败时仍显示最后一张有效图片，失败原因在设置行可见。正常显示条件下各页和六种材质均可辨认同一底图，图案比例正确。主题和材质变化后卡片、菜单及控件仍可读。 |
| 在深色、Acrylic 下单独恢复默认背景，再选一张图片，执行全局「恢复默认外观与布局」。再次选图后重新载入原型。 | 单独恢复后仍为深色、Acrylic，且恢复该材质的默认背景。全局恢复后为浅色、标准材质、默认背景。重新载入后新会话使用默认背景。正式宿主按其设置页声明的保存策略验证。 |
| 在有自选背景时，分别启用高对比度和减少透明效果，再各自关闭。 | 两种限制条件下均使用实色，能辨认控件、文字、状态和键盘焦点。恢复普通显示后重新出现当前选图。记录系统设置和实际回退。 |

先在「设置 → 外观」分别查找「毛玻璃」和「页面切换」。材质应列出 Normal、ElaMica、Mica、MicaAlt、Acrylic、DWMBlur 六种；转场应列出 None、Popup、Scale、Flip、Blur 五种。在浅色、深色下各切一遍材质，通过顶栏或设置切主题时，所选材质和转场保持。单独选 Acrylic，再把转场由 Blur 改为 None，确认毛玻璃仍被选中。用「预览」和真实的概览、设置、关于页签体验各转场，快速连切、后退、前进、中途关闭页签及转入受控插件页，核对最终页、历史和焦点。播放中关闭系统动画应立即显示当前目标，恢复动画后继续使用原选值。底部输出／问题的切换仍保持原高度。原型在浏览器验证选择、示意和状态；候选原生包需留 Qt/Windows 证据。

原生材质用本地 Windows 桌面复核。固定窗口位置和后方可辨认的图案，登记系统内部版本、显卡或远程会话、系统透明效果、高对比度、窗口激活状态。依次在主窗口、已打开且注册同步的另一 Ela 窗口和稍后打开的注册窗口检查材质、文字可读性和浅深切换。分别保存 Acrylic、标准以及一次系统限制下的实图，记录该项的用户选择、Windows 调用结果及实际回退。重启带偏好文件的宿主，核对两个字段独立往返；旧文件缺项沿用标准材质及无转场，某一项含未知值仍保留其他有效偏好。[六种窗口效果与原生边界](../../docs/ui-workbench-redesign.md#设置页复用-ela-示例)

从平台活动栏进入「设置」，确认目录依次包含外观、工作区布局、通知、开发者、快捷键。平台活动栏中的「设置」在以下操作中持续选中。检查主题、导航模式、用户卡片显隐、导航宽度、底部显隐与高度各占独立的 Ela 设置行。

| 操作 | 应观察到的结果 |
|---|---|
| 宽窗点「工作区布局」，再点末组「快捷键」，随后手动向上滚到外观。 | 搜索与左侧目录始终可见。点击后对应标题对齐正文视口起点。手动滚动时当前组随正文更新，页签数量和全局前进／后退历史保持原状。 |
| 缩窄设置页，在 Windows 150% 缩放下，用键盘逐组聚焦并激活末组。 | 顶部横向目录可滚动，聚焦项完整可见。正文独立纵向滚动。Tab 可到达设置控件，组名、当前值和焦点均可辨认。 |
