## 启动

在仓库根目录 PowerShell 运行已构建的演示：

```powershell
$env:PATH = "E:/Qt/5.15.2/msvc2019_64/bin;$env:PATH"
$env:QT_QPA_PLATFORM = 'windows'
& ./build/ela-msvc-debug/bin/cordis_ela_demo.exe
$LASTEXITCODE
```

Debug 与 Release 各执行一次；Release 路径为 build/ela-msvc-release/bin/cordis_ela_demo.exe。记录 Windows 版本、分辨率及缩放比例；至少检查本机常用缩放和 150%。
